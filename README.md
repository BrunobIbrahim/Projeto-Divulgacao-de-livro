# 📖 Divulgação de Livro - A Era Artificial

> Projeto desenvolvido durante meus estudos de **HTML e CSS** no curso da **DevMedia**.

---

## 📚 Sobre o projeto

Este projeto consiste em uma página de divulgação do livro **"A Era Artificial"**, apresentando informações sobre a obra, seu autor e uma breve descrição da história.

O objetivo principal foi colocar em prática os conhecimentos adquiridos durante os estudos de **HTML e CSS**, trabalhando com a estruturação da página e a estilização dos diferentes elementos e seções de conteúdo.
